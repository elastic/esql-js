# Highlight ES|QL

Syntax highlighting for [ES|QL](https://www.elastic.co/docs/explore-analyze/query-filter/languages/esql) (Elasticsearch Query Language) queries in `.esql` files.

Useful for reading and maintaining queries kept in test fixtures, integration tests, sample scripts, and shared snippets.

## Features

- Automatic file recognition by extension (`.esql`)
- Highlighting for commands, functions, operators, literals, parameters, comments, strings, numeric literals, time intervals, and type casts
- Comment toggling (`//` and `/* */`), bracket matching, and auto-closing pairs

## Installation

Search for **Highlight ES|QL** in the Extensions view, or run:

```sh
code --install-extension Elastic.highlight-esql
```

VSCodium, Cursor, and other VS Code forks install the same extension from [Open VSX](https://open-vsx.org/extension/Elastic/highlight-esql).

To highlight ES|QL in files with other extensions, select **ES|QL** from the language picker in the status bar, or add a file association:

```json
{ "files.associations": { "*.query": "esql" } }
```

## Development

The extension lives in the [`elastic/esql-js`](https://github.com/elastic/esql-js) monorepo under `packages/esql-vscode`. The grammar is not maintained here: it is generated by [`@elastic/textmate-esql`](https://github.com/elastic/esql-js/tree/main/packages/textmate-esql).

```sh
pnpm --filter highlight-esql build     # copy the grammar into syntaxes/
pnpm --filter highlight-esql package   # produce a .vsix
```
